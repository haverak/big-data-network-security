Это локальное аналитическое приложение на Python. Оно показывает исходные данные, воспроизводимую подготовку, девять интерактивных визуализаций и выводы. Данные берутся из реального [набора KDD99 на Kaggle](https://www.kaggle.com/datasets/toobajamal/kdd99-dataset).

## Быстрый запуск на Windows 11

Потребуются Windows 11, Python 3.12 и около 16 ГБ оперативной памяти. Для первого получения Python-пакетов нужен Интернет. Docker, WSL2, отдельный сервер и отключение защиты Windows не требуются.

1. Полностью распакуйте ZIP в отдельную папку, например `C:\Учеба\BigData_Bondarenko`. Не запускайте файлы прямо из окна архива. Пробелы и кириллица в пути поддерживаются.
2. Если Python 3.12 ещё не установлен, установите его со [страницы Python для Windows](https://www.python.org/downloads/windows/). При установке включите добавление Python в `PATH` или установку Python Launcher.
3. Дважды нажмите `setup_windows.cmd`. Скрипт создаст отдельную папку `.venv`, установит фиксированные пакеты из `requirements-lock.txt` через проверяемый установщик и выполнит подготовку данных. Исходный CSV при этом не перезаписывается. Дождитесь сообщения об успешном завершении.
4. Запустите `start_app.cmd`. Если браузер не открылся автоматически, перейдите по адресу **http://127.0.0.1:8501**.
5. Во время работы оставьте окно запуска открытым. Для остановки нажмите в нём `Ctrl+C`, затем закройте окно.

После успешной установки приложение использует локальные данные. Повторная настройка нужна при изменении зависимостей, переносе/повреждении `.venv` или необходимости заново построить подготовленный набор.

Список зависимостей приведён в `requirements.txt`; точные версии фиксируются в `requirements-lock.txt`. Установщик `scripts/install_dependencies.py` получает сведения и пакеты с официального PyPI, проверяет SHA-256, устанавливает пакеты из проверенного локального кэша и выполняет `pip check`. Он рассчитан на Windows x64 и Python 3.12 и работает только с `.venv` этого проекта. Временные папки `.dependency_cache` и `.wheelhouse` не нужны в итоговом ZIP; при необходимости кэш создаётся заново.

Скрипты всегда переходят в собственную папку через `pushd "%~dp0"`. Поэтому их можно запускать двойным щелчком либо из другой рабочей папки. Переменная `BIGDATA_NO_PAUSE=1` отключает ожидание клавиши при автоматической проверке скриптов; для обычного запуска она не нужна.

## Подготовка и нормализация

Конвейер запускается командой:

```cmd
.venv\Scripts\python.exe -m analysis.pipeline --force
```

Он читает неизменяемый файл из `data/raw/`, проверяет структуру, типы, пропуски, допустимость значений и дубликаты, затем сохраняет отдельный подготовленный набор и статистические сводки. Повторный запуск с `--force` пересоздаёт подготовленные результаты, сохраняя исходный CSV.

В исходной копии выявлены **348 435 полных повторов**; после удаления повторов остаётся **145 585 уникальных профилей соединений**. Для поставленного файла не обнаружены пропуски или строки, признанные некорректными проверками конвейера. Необычное значение `su_attempted=2` сохраняется и отмечается предупреждением, а не незаметно заменяется.

Числовые характеристики для сопоставления профилей преобразуются через `log(1+x)` и min–max-нормализацию. Такой порядок уменьшает влияние длинных хвостов и приводит выбранные признаки к сопоставимому масштабу. Исходные значения остаются доступны; длительность и объём на соответствующих графиках не выдаются за нормализованные физические единицы. Точные правила, параметры и результаты подготовки показаны в приложении и сохранённых сводках.

**Статистические выбросы автоматически не удаляются.** Экстремальная длительность или объём могут быть существенной характеристикой сетевой атаки. Выброс в статистическом смысле не равнозначен подтверждённому вторжению.

## Девять визуализаций

1. Соотношение нормальных и атакующих записей — кольцевая диаграмма.
2. Число записей по типам атак — столбчатая диаграмма.
3. Протоколы и класс трафика — составные столбцы.
4. Длительность по классу — точная эмпирическая функция распределения (CDF) в масштабе `log10(1 + секунды)`. Квартили у обоих классов нулевые, поэтому CDF информативнее вырожденной коробчатой диаграммы.
5. Суммарный объём передачи — гистограмма `log10(1 + байты)` с полными счётчиками.
6. Корреляция Спирмена девяти числовых признаков — тепловая карта.
7. Сервисы и класс трафика — составные столбцы, нормированные до 100%.
8. Нормализованные профили пяти признаков — радиальная диаграмма средних после `log(1+x)` и min–max-преобразования.
9. Частоты статистических выбросов пяти признаков — сгруппированные столбцы по правилам IQR/квантильного хвоста.

Все девять графиков используют **все записи текущей отфильтрованной подготовленной выборки**. Применяется предварительная агрегация; случайная подвыборка для этих графиков не используется. Числа на графиках относятся к очищенным уникальным профилям после указанных фильтров. Названия, единицы, описания показателей и выводы представлены в интерфейсе. При отсутствии записей для выбранного сочетания фильтров выводится понятное сообщение.

## Что ограничивает интерпретацию

- В используемых полях нет календарных временных меток. Нельзя делать выводы о всплесках атак по дням, сезонности или частоте событий в единицу реального времени.
- Это исторический контролируемый benchmark. Его распределения не доказывают распространённость современных атак и не оценивают безопасность конкретной действующей сети.
- Предоставлен 10%-поднабор исходного исследования; результаты не экстраполируются на весь исходный массив или Интернет.
- Удаление многочисленных повторов существенно меняет распределения. Поэтому анализ подготовленного набора описывает уникальные профили соединений, а не фактическую интенсивность событий. До/после очистки числа различаются явно.
- Известные метки набора используются как категории данных. Статистическая аномалия, высокий объём и корреляция не доказывают причинность или вредоносность отдельной записи.
- Пользователь подтвердил, что выбранный датасет не повторяет наборы одногруппников. Это подтверждение пользователя; самостоятельная проверка чужих работ не проводилась.

## Переносимый комплект

В ZIP используется одна корневая папка `BigData_Bondarenko/`. В неё входят исходный CSV и архив источника, подготовленные данные, метаданные и атрибуция, приложение, аналитический конвейер, установщик, тесты, итоговые отчёты и иллюстрации. Папки `.venv`, `.dependency_cache`, `.wheelhouse`, кэши Python/pytest и локальный `installation_manifest.json` в поставку не входят. На другом компьютере окружение создаётся заново через `setup_windows.cmd`.

Скрипт `scripts/package_project.py` по умолчанию только проверяет состав комплекта и показывает план, не создавая ZIP:

```cmd
.venv\Scripts\python.exe scripts\package_project.py
```

Создание архива выполняется отдельно с ключом `--create`, после готовности и проверки Word-отчёта и PDF-копии. Скрипт требует пару DOCX/PDF в `reports/`, проверяет отсутствие персональных абсолютных путей, контрольные суммы и целостность ZIP, сохраняет один корень и отказывается перезаписывать существующий архив. Проверка контейнеров DOCX/PDF не заменяет визуальный просмотр страниц.

Два сырых локальных журнала `setup_windows_test.txt` и `setup_windows_cold_test.txt` содержат рабочие пути конкретного компьютера и исключаются из поставки. ## Типовые проблемы

**Окно сообщает, что Python 3.12 не найден.** Установите указанную версию и заново откройте `setup_windows.cmd`. Существующая Python другой версии не удаляется.

**Ошибка установки пакетов.** Проверьте сообщение `pip` и подключение к Интернету, затем повторите настройку. Не отключайте защиту Windows и не устанавливайте пакеты из неизвестных источников.

**Папку перенесли, и `.venv` перестала работать.** Закройте приложение, удалите только `.venv` внутри перенесённой папки проекта и повторите `setup_windows.cmd`. Исходные данные и отчёты удалять не нужно. Виртуальные окружения не предназначены для переноса между компьютерами.

**Порт 8501 уже занят.** Остановите ранее запущенную копию приложения через её окно `Ctrl+C`, затем повторите запуск. Не завершайте посторонние процессы без необходимости.

**Браузер не открылся.** Пока окно запуска остаётся открытым без ошибки, вручную перейдите на http://127.0.0.1:8501. Приложение привязано к локальному адресу и не предназначено для публикации в сети.

**Исходный файл отсутствует или имеет другую структуру.** Используйте раздел «Если данные отсутствуют»; не редактируйте сырой CSV вручную и не подменяйте его другим набором с тем же именем.
