# Network Traffic Analytics

**Интерактивная система анализа сетевого трафика и событий информационной безопасности.**

Учебный проект по дисциплине «Системы больших данных». Приложение позволяет исследовать сетевые соединения, изучать распределение атак, анализировать характеристики трафика и выявлять статистические аномалии.

Разработано на Python с использованием Streamlit, Pandas, NumPy и Plotly.

## Возможности

- Анализ набора данных KDD Cup 1999, содержащего 494 020 записей.
- Очистка данных, удаление дубликатов и нормализация числовых признаков.
- Девять интерактивных визуализаций сетевого трафика.
- Анализ типов атак, протоколов, сетевых служб и характеристик соединений.
- Корреляционный анализ и обнаружение статистических выбросов.
- Фильтрация по протоколам, классам трафика, категориям атак и службам.
- Просмотр исходных характеристик и результатов обработки.
- Экспорт отфильтрованных данных в CSV.
- Тёмный интерфейс с несколькими аналитическими разделами.

## Датасет

Используется **KDD Cup 1999** — набор сетевых соединений с классификацией нормального трафика и различных типов атак.

Источник: [KDD99 dataset — Kaggle](https://www.kaggle.com/datasets/toobajamal/kdd99-dataset)

Оригинальный набор: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/130/kdd+cup+1999+data)

| Показатель | Значение |
|---|---:|
| Исходных записей | 494 020 |
| Исходных признаков | 41 |
| Классов меток | 23, включая normal |
| После удаления повторов | 145 585 |
| Удалено точных дубликатов | 348 435 |

**Примечание:** данные относятся к историческому экспериментальному сетевому трафику. Результаты не являются оценкой безопасности современных сетей.

## Аналитические возможности

Приложение включает девять визуализаций:

1. Соотношение нормального и атакующего трафика.
2. Распределение типов сетевых атак.
3. Статистика сетевых протоколов.
4. Анализ длительности соединений.
5. Распределение объёма переданных данных.
6. Матрица корреляции характеристик трафика.
7. Распределение атак по сетевым службам.
8. Сравнение нормализованных признаков.
9. Анализ статистических выбросов.

Все графики поддерживают взаимодействие с пользователем и пересчитываются при изменении фильтров.

## Установка и запуск

### Требования

- Windows 10/11 x64.
- Python 3.12.
- Подключение к интернету для первоначальной установки зависимостей.

### Автоматический запуск

1. Скачайте проект через **Code → Download ZIP** и распакуйте архив.
2. Запустите `setup_windows.cmd`.
3. После завершения установки запустите `start_app.cmd`.
4. Откройте приложение в браузере:

   http://127.0.0.1:8501

Скрипт настройки создаёт виртуальное окружение Python, устанавливает зависимости и подготавливает данные.

Исходный архив датасета включён в репозиторий. Если CSV отсутствует, он будет восстановлен из архива или загружен из закреплённого источника.

### Ручной запуск

Из корневой папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m analysis.download
.\.venv\Scripts\python.exe -m analysis.pipeline --force
.\.venv\Scripts\python.exe -m streamlit run app/main.py
```

После запуска веб-интерфейс будет доступен по адресу `http://127.0.0.1:8501`.


## Результаты исследования

После удаления точных повторов доля профилей с метками атак изменилась с **80,31% до 39,67%**. Это показывает, насколько структура исходного набора и выбранный способ обработки влияют на результаты анализа.

Среди атакующих профилей чаще всего встречается тип `neptune`. Основным протоколом в подготовленном наборе является TCP.

Подробные расчёты, графики и выводы представлены в папке `reports/`.
